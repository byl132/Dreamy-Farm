# 砍树视觉反馈笔记（chop-fx）

> **文档类型**：美术圣经配套 · 农场砍树动效/反馈笔记
> **作者**：林绘澄（美术方向 / art-director）v1.0
> **基调**：农场明亮、圆润、低饱和；**移动端控量**
> **硬约束**：纯代码旋转/位移（**无骨骼动画**）；木材掉落实时粒子**移动端限量**；尊重 reduced-motion。

## 0. 三阶段状态机（树摇晃 → 倒下 → 树桩）
树对象 = 一个 `pivot` 节点（位于树根，Y=0）+ 子 `mesh` 节点（树干+冠）。所有旋转绕 `pivot` 进行，使树**从根部倒下**。

| 阶段 | 触发 | 表现（纯代码） | 时长 |
|---|---|---|---|
| `SHAKE` | 每次挥斧命中 | pivot 绕 Z 轴微摆 `rot.z = sin(t*ω)*amp`，amp 随树 HP 下降**增大**（0.04→0.12 rad）；冠同相微缩放 punch | 每次命中 ~0.4s |
| `FALL` | HP=0 | pivot 从 0° → ~88°（绕 Z 或倒向玩家反侧），缓动加速（落地感）；末段 overshoot + 回弹 settle | 0.6–0.9s |
| `STUMP` | FALL 结束 | 隐藏/淡出树冠+上部干；显示短树桩（圆柱 ~0.3m，`#9C7450`）；可选 `regrow` 计时器重置 | 即时 + 渐隐 0.3s |

**缓动**：`SHAKE` 用 `sin` 衰减；`FALL` 用 `(0.16,1,0.3,1)` 反向（加速倒下）或 `1-(1-t)^2`；`STUMP` 淡出 `cubic-bezier(0.4,0,0.2,1)`。
**倒向**：固定倒向玩家**身后/侧面**（远离玩家），避免砸到相机。

## 1. 木材掉落 FX（Wood Drop）
**小木片飞溅**（复用于可砸陶罐碎片）：
- 生成 3–6 个小盒/球，材质 `ExploreSafeMaterial(#C9A06A)` / `(#9C7450)`（暖木，农场低饱和）。
- 物理：Lua 简易欧拉积分——初速随机（上抛+四散），每帧 `vel.y -= g*dt`，`pos += vel*dt`，落地后 0.1s 淡出；生命周期 0.6–1.0s。
- **移动端限量**：木片数 **≤4**（桌面 ≤8）；用对象池复用，避免每帧 new。圆润：小球/倒角小盒。

**飘字（Floating Text）**：
- `+1 🪵` 或 `+1 木材` 在命中点上浮 + 淡出（复用 `ShowMessage` 或轻量 floating label）。
- 农场明亮基调 → 文字用 **金 `#C9A227`** 或 **绿 `#4A7C59`**（正反馈色），**禁红**（红=危险，与农场治愈冲突）。
- 控量：玩家附近**同时仅 1 条**飘字；移动端可改为仅音画反馈不飘字（设置项）。

## 2. 屏幕 / 音画反馈
| 反馈 | 规格 |
|---|---|
| 命中确认 | 树体 scale punch `1.05→1.0`（≤200ms）+ 短暂自发光脉冲 |
| 相机微震 | 命中时相机偏移 ~0.03m / 0.1s（低频）；**reduced-motion 或低端机关闭** |
| 音效 | `PlaySfx("chop")` 每次命中；倒地 `PlaySfx("tree_fall")`（由音频主理落地） |
| 体力 | 每次挥斧耗体力 → 顶部体力芯片做 `-N` 闪动（金边脉冲） |
| 收尾 | 树桩出现 + `ShowMessage("🌳 获得木材 x N")` 或飘字 |

## 3. 移动端控量（硬约束）
- 木片粒子 **≤4**（桌面 ≤8），对象池复用，生命周期 ≤1.0s。
- 单玩家附近飘字 **≤1 条并发**；提供设置"关闭飘字（仅音画）"。
- 相机微震仅在中/高画质开启；`STUMP` 淡出在低端机改为**瞬切**。
- `SHAKE`/`FALL` 的旋转每帧仅改 `Node:SetRotation`，无骨骼、无额外 mesh 创建。
- 全部动效受「动态效果」开关 / `prefers-reduced-motion` 接管。

## 4. 落地点（Handoff → 工程）
- 树节点约定：统一加 `Pivot` 子节点（根部），砍树逻辑只转 pivot。
- 树桩：本地圆柱 `SceneUtils.CreateCylinder(..., ExploreSafeMaterial(#9C7450), ...)`，高 ~0.3m；`regrow` 计时由玩法定。
- 木片/飘字复用 `ExploreSafeMaterial` + `ShowMessage`；不引入新材质技术。
- 与策划 GDD 对齐：砍树产出（木材数量、体力消耗、是否有概率掉特殊物）由设计定，视觉仅做反馈层。
