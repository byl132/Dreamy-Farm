## 0. 总览与诊断（为什么需要这份圣经）

当前场景视觉处于**混搭（inconsistent）**状态：

| 类别 | 现状 | 问题 |
|------|------|------|
| 已用 `.mdl` 的物件 | 商业街、牧场、农田多数低多边形模型 | 风格不统一、部分"简陋" |
| **主屋（玩家家）** | `RealisticBuildings.CreateHouse` **强制走方块 fallback**（`CreateHouseFallback`） | 注释称 `MainHouse.mdl` 在部分视角"露出拆分网格"被禁用 |
| 水井 / 风车 / 棚屋 | 纯方块 `Box.mdl`/`Sphere.mdl` 程序化拼 | 简陋、与模型建筑观感割裂 |
| 装饰 | 花丛(box+sphere)、尖桩栅栏(box)、湖边码头(box)、`RealisticSceneDetails` 方块家具 | 同上 |

**关键资产清点（已存在、可零成本复用）**：
- `assets/Meshes/FarmSlices/` 共 **11 个 `.mdl`**：`MainHouse / Warehouse / RanchBarn / Stable / LongBarn / Greenhouse / Shop / Carpenter / Smithy / SiloTower / FenceSegment`。
- 经代码核对（`RealisticBuildings.lua` 的 `HOUSE_STYLE_CONFIGS` 与 `FarmRanch.lua`），**实际被场景使用的只有 `MainHouse`(被所有棚屋缩放复用)、`LongBarn`、`Greenhouse`、`SiloTower`、`FenceSegment`**；而 **`Warehouse / Shop / Stable / RanchBarn` 四座专属模型（`Smithy`/`Carpenter` 已在商业街使用，非沉睡）当前代��完全未引用（沉睡资产）**。
- `assets/Meshes/LowPoly_Farm_Pack.mdl`（74MB 整包）+ `prefab` + `Materials/LowPoly_Farm_Pack_00_farmmaterial.xml`：另一套农场模型包（含材质），可作为植被/小道具的补充池。
- 角色：`farmer.mdl / npc_male.mdl / npc_female.mdl` 已是正规模型。

> **结论**：全新风格≠全部重做。核心策略是"**唤醒沉睡模型 + 统一重材质（PBR）/ 一致暖色板与光照**"，方块物件仅在无对应模型时就地升级到同一 PBR 语言。详见第 9 节。

## 1. 一句话风格定位（Style Tagline）

> **风格化写实 PBR（Stylized Realistic PBR）**——暖色调、治愈氛围、细节丰盈的农场生活模拟；在移动端廉价 PBR 下保持多端流畅，让"真实可触的农场"既可信又轻盈。

**关键词（可落地、便于找参考与对齐工程）**：
`stylized` · `PBR` · `warm-cozy` · `detailed` · `cross-platform`

> 方向说明：本方向**直接走引擎现有 PBR 着色**（UrhoX `Techniques/PBR/*`），不做 toon/cel 渐变 ramp、不做反相壳描边、不引入额外着色技术。风格化来自"暖色反照率 + 哑光粗糙度 + 细节密度（材质层次 / 场景 dressing）"，而非卡通描边。纯 toon / 水彩 / 黏土等方向本阶段不做。

## 2. 参考作品 / 情绪板描述（Moodboard Brief）

用文字描述参考方向，便于后续美术找图与对齐。**整体调性：写实治愈、细节丰盈、暖色 PBR**——在"真实农场"的可信质感之上做轻微风格化温暖，而非卡通夸张。

1. **《星露谷物语》+ 3D 化**：温暖小镇、圆润建筑轮廓、强可读配色。取其"治愈可读性"与布局语言，但升级为统一 3D 写实 PBR 质感而非像素 / 绘本。
2. **《A Short Hike》**：哑光、低对比、清新自然、可信的低多边形写实——"从容节奏（P5 支柱）"的视觉化身，也是 PBR 在移动端流畅的典范。
3. **《Spiritfarer》**：暖色灯火、柔光天空、治愈渡轮氛围——取其**暖色治愈调性与光照**，而不取其手绘描边绘本层。
4. **《Everdream Valley / 梦境谷》**：田园农场、圆润亲切比例、丰富植被——取其"丰盈可爱"的方向，但落地为风格化写实 PBR 而非糖果色卡通。
5. **写实治愈背景美术（如吉卜力背景美术、farmscape 概念图）**：可信的光影、空气感、暖调远景，作为"细节丰盈 + 梦幻夜景 + 植被"的色调与层次参考。

**情绪关键词**：warm（暖）、realistic-cozy（写实治愈）、detailed（细节丰盈）、safe（安心）、readable（可读）、soft-light（柔光）。

## 4. 材质与着色方案（Material & Shading）

### 4.1 着色范式决策：**风格化写实 PBR（引擎现有 PBR）为主**

| 维度 | 决策 | 理由 |
|------|------|------|
| 着色模型 | **引擎现有 PBR**（`Techniques/PBR/PBRNoTexture.xml` 等，走 albedo/roughness/metallic 标准管线） | 直接复用引擎 PBR，零新增着色技术；移动端廉价、稳定，规避自定义 toon/描边着色器的开发与维护成本。 |
| 风格化来源 | **暖色反照率 + 哑光偏高粗糙度 + 高细节密度** | "风格化"不靠卡通描边，而靠色板（第 3 节）+ 哑光材质 + 材质层次 / 接缝 / 木纹（法线近似）表达"比真实更温暖可爱一点"。 |
| Fresnel / 环境反射 | **用 PBR 自带的轻微 fresnel 与 env-map 环境反射做柔化**（sky-tinted，强度低） | 替代 toon rim 的"柔光边缘"效果，PBR 天然具备，无需额外着色器；低强度避免塑料感。 |
| 卡通描边（Outline） | **默认不描边**。描边仅作为可访问性"强对比模式"的可选项（见第 8 节），非美术基线 | 移动端 / WebGL 后处理全屏描边贵、反相壳也增加 draw call；默认关闭以保证多端流畅与真实感。 |
| Emissive 自发光 | **使用**，用于温馨夜景（灯笼、黄昏窗光） | `MatEmissiveColor` 暖色 (1.0,0.7,0.4) × 强度 1.5–2.5；夜景靠暖灯而非环境提亮，治愈暖光保留。 |

### 4.2 参数方向（供工程主理落地 · 风格化写实 PBR）

> 数值为 `RealisticMaterials.MakePBR(Color(r,g,b))` 的 roughness / metallic 输入意向；反照率见第 3 节色板。

| 材质类别 | Roughness | Metallic | 说明 |
|----------|-----------|----------|------|
| 墙面 / 灰泥（暖白） | 0.70–0.85 | 0.0 | 哑光偏暖，柔光不刺眼 |
| 木材（暖橡 / 深木） | 0.60–0.80 | 0.0 | 哑光木纹感，靠色板 + 法线近似木理 |
| 石材（暖灰 / 地基 / 井石） | 0.50–0.70 | 0.0 | 略带微反光，仍哑光 |
| 陶瓦 / 谷仓红屋顶 | 0.65–0.85 | 0.0 | 哑光陶土 |
| 金属件（灯笼架 / 五金 / 筒顶圈） | 0.35–0.50 | 0.3–0.5 | **唯一低 roughness 处**，金属感克制、不镜面 |
| 玻璃 / 温室（半透薄荷） | 0.10–0.30 | 0.0 | 半透 + 低 roughness 近似玻璃，α≈0.5 |
| 植被 / 草地 | 0.80–0.95 | 0.0 | 哑光；轻微 subsurface 感（见下） |
| 花朵 / 叶 | 0.70–0.90 | 0.0 | 轻微 subsurface 感（暖光透射观感），**不做复杂 SSS 着色**，靠色板亮度表达 |

**通用**：Fresnel / 环境反射用 PBR 默认（sky-tinted env-map，强度低）；Emissive 夜景 `暖 (1.0,0.7,0.4) × 1.5–2.5`；**Outline 默认关闭，仅可访问性"强对比模式"可选开启**（见第 8 节）。

### 4.3 着色落地路径（重要 · 直接走现有 PBR）

> 本方向**直接走引擎现有 PBR**（`Techniques/PBR/PBRNoTexture.xml` 等）。**PBR 近似即最终方案**，无需 toon technique，也无需"过渡期切换"。

**落地要点（供工程主理 程基岩）**：
- 全部材质用 `RealisticMaterials.MakePBR(Color(r,g,b))` 套用第 3 节色板 + 第 4.2 节 roughness / metallic；无需新增着色技术。
- 柔光边缘 / "梦幻感"由 PBR 自带的轻微 fresnel + sky-tinted env-map 环境反射自然产生，无需额外 rim 着色器。
- 夜景暖灯用 `MatEmissiveColor (1.0,0.7,0.4) × 1.5–2.5`（保留原治愈暖光）。
- 植被 / 花朵的"轻微 subsurface 感"仅通过**偏高亮度反照率 + 高 roughness 哑光**近似表达，**不做复杂 SSS 着色器**（移动端成本考量）。
- 默认关闭描边；若可访问性"强对比模式"需要，仅在此模式开启反相壳描边（见第 8 节），属可选项而非基线。

> 结论：本阶段**没有"先近似后切换"的过渡负担**——现有 PBR 即为目标形态，工程侧零新增着色器即可落地。

## 5. 光照与氛围（Lighting & Mood）

| 维度 | 设置 | 说明 |
|------|------|------|
| 方向光（太阳） | 色温 ~3000–3500K，颜色 (1.0,0.92,0.78)；仰角 35–45°，方位使阴影柔和拉长 | 暖金 Hour 感，低对比不刺眼 |
| 阴影 | PCF 软阴影，bias 调优避免漏光（注意主屋网格接缝处） | 柔边 |
| 环境光（Hemisphere） | 天空色=暖奶油，地面反弹=柔绿；强度 **0.55–0.70**（偏亮） | 治愈、低 harsh 对比 |
| 雾 | 指数雾，颜色=天空地平线，密度 **0.005–0.012**（低） | 梦幻景深、柔化远景边界、统一调性 |
| 昼夜 | **夜景=靛蓝天空 + 暖色灯笼点光(emissive) + 冷调环境补光，绝不纯黑** | 呼应 P5"从容/安全"；夜也温馨 |

> 昼夜由 `TimeSystem` 驱动（GDD 确认 20 分钟/天）。夜景是"梦幻"的高光时刻，灯笼 emissive 是核心。

## 7. 道具 / 植被设计语言（Prop & Foliage Language）

统一规则（所有道具/植被必须遵守，确保"家族感"）：

1. **圆角倒角优先（避免锐利方块边）**：任何可见几何体不得保留原始 `Box`/`Sphere` 直拼的 90° 锐利方块边；保留圆角倒角与有机外形，使低多边形网格仍显亲和，但不刻意夸张。
2. **风格化写实比例（轻微"比真实更可爱"，弱化）**：可略放大花朵、略圆润树冠、略饱满果实，但幅度克制——整体是"真实农场的可信比例"，而非卡通夸张；石头保留自然块面 / 鹅卵感。
3. **细节密度优先**：通过**材质层次 + 接缝 + 木纹 / 石理（法线近似）**表达丰富度，而非靠纯色块；同一物件可见多层材质（木墙板缝、石材砌缝、屋顶瓦垄），提升"细节丰盈"观感。
4. **配色从属（写实暖调）**：木质 / 石材用第 3 节 PBR 材质色（哑光暖调）；点缀用花粉色 / 奶油黄 / 天空蓝，且**同色系在全局重复出现**（如全图"花粉色花"是统一符号）；亮度区间一致，避免某物件过暗 / 过亮破坏暖调统一。
5. **可读剪影**：远处可辨识（筒仓高瘦、谷仓宽、主屋带山墙 + 烟囱），靠轮廓而非靠描边；不靠细节堆砌，但允许更丰富的近景材质层次。

## 8. 可访问性分级（Accessibility Tiers）

> UX 规格（由文策渊产出）**必须引用本分级**。以下为美术/视觉侧承诺。

### Basic（基础 · 所有平台默认达标）
- UI 文本对比度 ≥ WCAG AA（4.5:1）；最小字号达标、HUD 可读。
- 对话/任务**字幕**默认开启。
- 交互色**不**仅用红绿区分（蓝/黄/橙 + 图标）。
- 3D 场景**高对比模式**：提升方向光强度、降低雾浓度、增强英雄建筑描边。

### Standard（标准 · 推荐默认）
- 含 Basic 全部。
- **色盲安全调色板模式**：对 Deuteranopia / Protanopia / Tritanopia 三种模拟校验通过的配色；UI 强调色切换为色盲安全组。

## 9. 与现有低多边形资产的衔接策略（Reuse Strategy · 核心）

> **原则**：全新风格 ≠ 推翻重做。用"**唤醒沉睡模型 + 统一重材质（PBR）+ 一致暖色板与光照**"以近零成本获得统一视觉。

### 9.1 FarmSlices 资产使用现状（代码核对结论）
| 模型 | 当前代码状态 | 新风格处置 |
|------|--------------|-----------|
| `MainHouse.mdl` | **仅被棚屋缩放复用**；玩家家自身禁用（走方块 fallback） | **唤醒用于玩家家**（见风险） |
| `LongBarn.mdl` | 已用（非 fallback 路径） | 重材质沿用（A） |
| `Greenhouse.mdl` | 已用 | 重材质沿用（A） |
| `SiloTower.mdl` | 已用 | 重材质沿用（A） |
| `FenceSegment.mdl` | 已用 | 重材质沿用（A） |
| `Warehouse.mdl` | **未引用（沉睡）** | 接回仓库（A） |
| `Shop.mdl` | **未引用（沉睡）** | 接回商店（A） |
| `Smithy.mdl` | 已用（商业街 `TownEntrancePlaza`） | 重材质沿用（A） |
| `Carpenter.mdl` | 已用（商业街 `TownEntrancePlaza`） | 重材质沿用（A） |

### 9.2 四步统一法
1. **唤醒沉睡模型**：将 `Warehouse/Shop/Stable/RanchBarn` 四座 `.mdl` 接回对应建筑（`Smithy`/`Carpenter` 已在商业街使用，无需重复接回），改 `RealisticBuildings.CreateShed` 的 `HOUSE_STYLE_CONFIGS` 指向专属模型而非全用 `MainHouse` 缩放。**零新建模成本**。
2. **统一重材质（Re-materialization）**：用一个协调的 `MatDiffColor` 色板覆盖每个 mdl 的各子物体材质。因 FarmSlices 各模型拓扑/UV 相似，套用**同一套色语言**即可让原本各异的导入模型"瞬间统一"。
3. **统一 PBR 材质 / 暖色板 / 一致光照**：所有建筑走同一套 PBR 材质（第 4 节）+ 同一暖色板（第 3 节）+ 同一暖金方向光与 hemisphere 环境（第 5 节）→ 统一的风格化写实农场观感。
4. **LowPoly_Farm_Pack 作补充池**：74MB 整包含植被/小道具，可作为花丛/灌木/木箱等来源，**重材质**到新色板后并入。⚠️ 预算注意：整包 74MB 需 LOD/拆分按需加载，避免一次性入场景。

### 9.3 仅方块、无对应模型的物件 → 就地升级（B 类）
水井、风车、院门、出货箱、`RealisticSceneDetails` 家具、湖边码头/栏杆、路灯、路牌、花丛（fallback）等：无 `.mdl` 可用，则在 Lua 程序化层**改用倒角基本体 + 新 PBR 材质（暖色板 + 哑光粗糙度）**，使其至少共享"材质/光照/圆角语言"，与建模建筑同属一个家族（详见资产规格文档的 B 类判定）。

### 9.4 唯一需全新建模的候选（C 类）
**风车**：当前仅有方块 fallback，且无对应 `.mdl`。若保留风车作为地标，建议**全新生成/外部建模**（低多边形写实风车，统一 PBR 材质），属 Phase 4 可选；否则可在 Phase 1 先用升级版程序化风车过渡。其余物件均可在 A/B 内解决，**不需要全面外包建模**。

### 9.5 最大风险（务必主理人知悉）
> **`MainHouse.mdl` 网格接缝问题**：现代码因"部分视角露出拆分网格"禁用该模型、改用方块。新风格要唤醒它，**必须先在全部相机角度验证接缝**——否则"全新风格的主屋"仍会是破绽。解决路径：(a) 美术/工具链修复 mdl 拆分网格（合并/重加权）；(b) 靠 PBR 暖色板 + 软阴影 + 法线近似掩盖接缝；(c) 若不可修复，主屋退回"升级版程序化"（B 类）而非方块。此风险需在 Phase 1 开头由工程+美术联合验证。
