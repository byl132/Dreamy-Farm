## 0. 背景与问题诊断前提

真机测试（TapTap Maker）反馈四类世界空间（3D）问题：

1. **集市场景地面缺失**——表现为一块扁平的灰 / 白平面。
2. **集市建筑无内部**——建筑仅有外壳，无可进入 / 可用的室内。
3. **玩家房屋无法上二楼**——二楼不可达。
4. **玩家房屋需要清晰的房间分隔**——室内分区不明确。

> ⚠ **关键前提**：当前 `art-bible.md` 是**纯 UI（2D）美术圣经**，完全未覆盖 3D 世界 / 地形 / 室内 / 光照。本文件是 3D 世界美术方向的**首份补充基线**，须与 UI 圣经共用同一套色彩 token 与调性，并反向推动美术圣经增加「世界 / 3D 美术」章节（见第 3 节）。

> ⚠ **引擎一致性（已解，B1）**：`art-bible.md` 曾写「引擎：Unity」，与 `dream-farm-concept.md` 的「UrhoX + TapTap Maker」及真机测试平台冲突。此冲突已由 team-lead 在 B1 拍板锁定 **TapTap Maker / UrhoX**（非 Unity），见 §3.1 与 §4；本文件 §1-B.3 格式已据引擎锁死（KTX2/Basis + 平台回退），下文不再标注待确认。

## 第 1 节 · 集市场景地面 / 地形

### 1.1 诊断：灰白平面根因（B2 已取证 ✅）

**美术方向初判仍成立，但根因比「缺资产 / 未绑定材质」更根本**：真机灰白平面，本质是**当前渲染管线根本不支持贴图**下的"正常"表现。team-lead 在真实仓库 `E:/trae/dreamy farm` 取证：

- **取证 1 · 资产从未生产**：`assets/` 仅有 `audio / generated / image / Materials / Meshes / Prefabs / Textures` 七子目录。`assets/Textures/` 里只有一张 `menu_background.jpg`；`assets/image/` 全是 UI 图 / NPC 立绘 / 过场图；**零张** ground/dirt/soil/grass/stone/terrain/tileable 类地面贴图。
- **取证 2 · 材质管线只吃纯色（关键）**：`scripts/scene/RealisticMaterials.lua` 的构造函数 `MakeUnlit / MakePBR / MakePBRAlpha / MakeWater / MakeAnimatedWater / MakeEmissive` **全部 technique 名带 `NoTexture`**，模块内无任何 `SetTexture / DiffMap` 调用。管线只吃 `Color + roughness + metallic` 三参数。集市地面的灰白正是 `PlazaScene.lua:98` / `TownEntrancePlaza.lua:1589` 调 `MakePBR(Color(...), 0.85, 0.0)` 的必然结果。

> **结论（写死，避免后人按错误前提规划）**：本轮（Tier 1）**不能**用贴图做地面。§1.2/§1.3/§1.4 的贴图方案整体降格为 **§1-B Tier 3 贴图管线升级**（前置：engineering 先给 `RealisticMaterials` 加支持 DiffMap 的 technique）。本轮止血走 **§1-A 纯色管线**。

### 1-A · Tier 1 纯色管线止血方案（本轮落地 · 重点）

**硬约束**：地面只能用「纯色 quad / 简单几何 + roughness + metallic」拼视觉层次，**禁止任何贴图**。管线调用形如 `RealisticMaterials.MakePBR(Color, roughness, metallic)`（PBRNoTexture）。集市范围：`WorldMapConfig.lua:83` center `(10,0,43)`，尺寸 24×18。

|---|---|---|---|---|---|

| **G0b** | 压实土 变化色 A | `#A06E42` | 0.92 | 0.0 | 2–4m 随机斑块，与 G0 拼 |
| **G0c** | 压实土 变化色 B | `#BD8660` | 0.88 | 0.0 | 同上，制造大尺度斑驳 |
| **G1** | 石板走道 | `#9A8C78` | 0.70 | 0.0 | 2.0–2.5m 宽条带 |
| **G1g** | 走道勾缝（深） | `#5D4030` | 0.95 | 0.0 | 0.15–0.25m 窄条（走道与土之间） |

> 所有色值锁定在**暖土家族**（terra/stone/dirt/green 派生），**禁止高饱和色**——任何跳色都会让色块"弹出"成马赛克（见 1-A.4）。

#### 1-A.2 几何排布逻辑

- **主面**：G0 一块 24×18 quad 铺满集市；其上以 G0b/G0c 随机 2–4m 斑块做斑驳（非均匀填充，是反马赛克第一招）。
- **走道**：主脊柱一条 ~2.5m 宽沿 z（南北）穿过集市中心（x≈10）；横向过道在 z≈37 / 43 / 49（约每 6m 一条）。走道条边缘做 **±0.3m 顶点抖动**，避免笔直拼贴感。走道与土之间夹 G1g 勾缝窄条。
- **磨损区**：G2 置于实际摊位/交互点坐标下——市集摊位 `(14.5,40.5)`、公告栏 `(8,39)`，及后续摊位槽位；每块 1.5×1.5m，随机旋转 ±15°，读作"被踩实的角落"。
- **过渡带**：G3 1.5–2m 宽带铺在**朝农田一侧**的集市边缘（具体哪条边接农田由 engineering-lead-3 按 WorldMap 确认），先用 G3b 0.5m 缓冲与 G0 相邻，伪造无贴图的"渐变"。
- **尺度层级**：大主面 → 中走道 → 小磨损块 → 微小 prop = 4 级尺度，骗眼读成"一个地方"而非"瓷砖"。

#### 1-A.3 纯色小 prop 撒点（细节密度）

- **用**，但克制：碎石 / 干草 / 落叶三类纯色小方块，色值见 1-A.1 的 P 行。
- **密度**：全集市 432 m² 上限 **40–60 个**实例（≈1 个 / 2–3 m²），低密度避免杂乱与低端机开销。
- **分布**：聚在摊位基座与边缘，避开走道正中；尺寸 0.15–0.4m，随机旋转 + 平贴地面（Y=0）。
- **作用**：在无贴图下用微尺度色点模拟"泥土颗粒感"，是低成本破平的关键。

#### 1-A.4 反马赛克手法（本方案最大失败风险，正面给）

纯色拼贴最易读成"色块马赛克"。依次落实：

1. **大尺度色斑，不匀填**：G0 主面必须混 G0b/G0c 斑块（2–4m 聚类），让地面有"大块斑驳"而非"一整片同色"——这是 NoTexture 下最核心的一招。
2. **roughness 调制**：每块 roughness 在 0.7–0.95 拉开，光在不同块上捕捉不同，读作材质差而非平涂。
3. **勾缝做"有意接缝"**：走道与土之间夹 G1g 深色窄条，边界读作"铺装缝"而非"硬切马赛克边"。
4. **不对称手摆**：绝不棋盘格；走道/磨损块跟随真实摊位坐标（非网格），边缘抖动 ±0.3m、旋转 ±15°。
5. **4 级尺度层级**（1-A.2 末）：大→中→小→微，制造景深阅读。
6. **色调纪律**：全暖土家族、低饱和、小步 hue；绝不引入跳色。

### 1-B · Tier 3 贴图管线升级方案（登记为未来项 · 不在本轮）

#### 1-B.1 材质 / 风格（对齐视觉锚点 3、调性「写实色调 + 卡通表现」）

| 维度 | 方向 | 说明 |
|---|---|---|
| **基色** | 暖沙 `#F0E4D0` → 赤陶 `#C4854A` 过渡 | 集市地面以「压实沙土 + 走道石板」为主，避免纯绿草（那是农田区语义）。 |
| **纹理** | 平铺（tileable）泥土 / 沙地 albedo + 轻噪点法线 | 叠加细微碎石 / 干草颗粒，呼应锚点 3 的「可信泥土肌理」；不要高对比卡通描边。 |
| **走道** | 暖灰石板 `mix(#8B5E3C, #A08060)` | 摊位间留规整石板路，引导动线，也作功能性路径（无障碍坡道沿此铺设）。 |
| **边缘处理** | 向农田区渐变到嫩绿 `#7CB342` | 集市与农场交界处用植被 / 矮篱笆软过渡，强化「邻里温情」（P4）。 |
| **风格控制** | 低饱和、柔和高光、暖棕投影 | 与 UI 毛玻璃柔影一致（锚点 2），拒绝硬黑边 / 荧光色（违反圣经 §1.4）。 |

**材质类型建议**（Tier 3 启用）：
- 引擎 Lit/Standard 等效；albedo + normal + roughness/AO；顶点色 / 贴花做摊位油污、磨损细节。
- 地面**必须开 mipmap**（美术圣经 §9.7 已明确 3D / 世界空间资产开 mipmap）。

#### 1-B.2 LOD 与多端性能

集市场景是玩家高频停留区，又要多端（Web / iOS / Android 中低端），LOD 必须前置：

| 层级 | 内容 | 触发 |
|---|---|---|
| **Base** | 完整地形网格 + 法线 + 中分辨率贴图（1024–2048） | 近景 / 桌面 |
| **LOD1** | 简化网格（减面 40–50%）+ 合并材质 + 贴图 512 | 中景 / 移动中端 |
| **LOD2** | 极简平面 + 单色 / 低分辨率贴图（256） | 远景 / 低端机 |
| **Culling** | 超出视距整体剔除 | 所有平台 |

- 集市若为**单一大平面**：靠纹理 mipmap + 材质分级即可，未必需要几何减面；重点是**贴图分辨率按设备档位切换**。
- **性能档位建议**（呼应概念 §7 性能预算）：高 / 中 / 低三档，分别走 Base / LOD1 / LOD2 + 关实时阴影只留烘焙光。
- 地面不参与实时阴影接收的高频更新；用**烘焙光照贴图 + 一张暖色环境光**即可（见 §2.4 光照）。

#### 1-B.3 命名与交付格式（延展美术圣经 §9.6，Tier 3 启用）

沿用 snake_case 全小写；新增 `env_*` / `mat_*` / `tex_*` / `prop_*` 前缀（`tex_*` 仅 Tier 3 贴图管线使用）：

| 类别 | 模板 | 示例 |
|---|---|---|
| 世界环境网格 | `env_<scene>_<object>[_lod<n>]` | `env_market_ground`、`env_market_ground_lod1` |
| 材质球 | `mat_<object>[_<variant>]` | `mat_ground_dirt`、`mat_path_stone` |
| 世界贴图 | `tex_<object>_<map>_<size>` | `tex_ground_dirt_albedo_2048`、`tex_ground_dirt_normal_1024` |
| 集市道具 | `prop_market_<name>` | `prop_market_stall`、`prop_market_crate` |

- **格式**（Tier 3 启用，引擎已锁 = TapTap Maker / UrhoX）：源纹理 PNG/RGBA + sRGB；交付用 **KTX2（Basis Universal）** 作为跨端（Web/iOS/Android）单一可转码格式，平台回退——Android: ETC2（基线）/ ASTC（高质量）；iOS: ASTC / PVRTC；世界贴图**开 mipmap**。具体导出目标在 Phase 3 与 engineering-lead 最终确认（UrhoX 贴图管线）。
- 贴图**开 mipmap**；UI 用贴图才关 mipmap（圣经 §9.7 已定）。

## 第 2 节 · 玩家房屋室内分区

> 本节定义**最终视觉身份（Tier 3 美术基线）**；分区策略（房间数 / 坐标 / 动线 / 两层功能错位）已据 design-strategist `interior_design_spec.md`（§3.2/§3.3）落定（B3 已解）。`Floor-as-Scene` 上楼机制由 engineering-lead-3（Tier 2）实现，本表为分区表达与扩展的视觉规格。

### 2.1 楼层与九区方案（已定 B3，坐标源自 interior_design_spec.md §3.2/§3.3）

主屋 16 宽 × 11 深 × 5.30 高，采用**软分区**（矮墙 / 家具组 / 地板材质，不做全封闭隔墙）。两层功能错位：**一楼＝生活层（功能循环：吃/暖/存/造，高频、路过式），二楼＝自我层（身份认同：睡/记/藏/展，低频、仪式式）**——两层不重复，避免支柱漂移。

**上楼机制（Floor-as-Scene）**：不改角色控制器，不做 Y 轴踩踏；靠楼梯井 E 的交互点 `house_upstairs` 切到二楼场景（复用已上线的「牧场↔放牧区」切场景机制），二楼出生点在楼梯平台 I。现有两个禁入盒（`HouseLoftNoEntry` / `HouseStairBox`）**保留**，作用是防玩家钻进楼梯几何体——美术侧据此把楼梯井表现为"可见但不可穿"的通道，而非可行走地面。

| 层 | 区 | 名称 | 坐标范围（房间中心为原点） | 空间性格（净高） |
|---|---|---|---|---|
| 一楼·生活层 | **A** | 客厅/起居区（进门正对，通高中庭） | x∈[-4,4], z∈[0,5.5] | 挑空 5.30m，明亮、呼吸感 |
| 一楼·生活层 | **B** | 餐厨区（左后） | x∈[-8,-1], z∈[-5.5,-0.5] | 阁楼下 2.55m，低矮包裹温暖 |
| 一楼·生活层 | **C** | 壁炉区（正后，通高烟囱） | x∈[-1,3], z∈[-5.5,-3.5] | 通高烟囱，聚焦暖光源 |
| 一楼·生活层 | **D** | 储藏/工坊角（右前） | x∈[4,8], z∈[1,5.5] | 通高中庭，功能照明 |
| 一楼·生活层 | **E** | 楼梯井（左墙） | x∈[-7.8,-6.3], z∈[-4.7,-1.1] | 阁楼下，通道（不可行走） |

| 二楼·自我层 | **I** | 楼梯平台（落脚点/spawn） | x≈-7, z≈1.5 | 二层出生点，过渡暖光 |

**二楼调性（服务"自我层"情绪）**：整体**私密、低照度暖光**，与一楼通高中庭的明亮开放形成对比——"上楼"这个动作本身承载「回到只属于我的地方」的仪式感（P3 自我表达 / P1 治愈）。二楼**不做任何生产/交易功能**，刻意零产出，仅承载睡/记/藏/展。

**⚠ 美术硬约束（源自 geometry 取证，落地不可违反）**
- **烟囱槽**：阁楼中间为通高烟囱让出 0.7m 槽，二层家具布局**必须避开 x∈[-0.35, 0.35]**。
- **斜顶穿模**：二层净高约 2.5m，边缘有斜顶；**衣柜/陈列架等高家具不贴最外侧墙**，避免穿模。
- **漏光缝**：右后角 x∈[7.0,8.0]、z∈[-5.5,-1.0] 为 1m 宽通高窄缝，会漏光到二层；此处灯光/材质需做过渡处理，避免二层出现突兀光斑。
- **可达性**：E/I 上下楼交互点用品牌色描边 + 图标标牌；楼梯踏面高对比金边（§2.2 E 行），保留禁入盒防穿模（修正 Bug 3 二楼不可达）。

### 2.3 房间分隔手法（修正 Bug 4：清晰分区）

要求「分区清晰但不压抑」，呼应 cozy 基调，**不用全高实心墙一刀切**：

1. **地面色块分区**：每间房地板用不同基色 / 地毯界定（如客厅绿毯、厨房赤陶砖），玩家靠脚下颜色即知所在房间。
2. **半高墙 / 拱门 / 矮柜**：分隔用 1.1–1.3m 矮墙 + 拱门过渡，保持通透与治愈感，同时明确边界。
3. **门框品牌色描边 + 标牌**：每间房门框用对应房间主色描边，配「图标 + 文字」标牌（非纯色编码，见 §2.4）。
4. **家具锚点**：用大型家具（书架、沙发、餐桌）作天然隔断，既是分区也是功能。
5. **天花 / 灯光分区**：不同房间用不同色温 / 灯具，强化空间辨识。

### 2.4 室内光照与可达性（Accessibility）

**光照**
- 主光：**烘焙暖色光照贴图 + 一张暖环境光**（避免实时阴影开销，呼应概念 §7 性能预算）。
- 锚点 5「夜晚暖灯农场」延伸至室内：入夜后门厅 / 客厅标牌、楼梯踏面亮起暖金小灯，营造「归家」安全感。
- 禁止过暗房间（违反对比度基线）；最暗区域也须保证可辨物体轮廓。

**可达性（衔接美术圣经 §8 Basic 级）**
1. **色彩非唯一信息通道**：房间识别 = 颜色 + 图标 + 文字标牌三重编码；色盲友好（Standard 路线）用形状区分（方=客厅、圆=厨房等）。
2. **对比度**：室内可交互物体（门把、开关、标牌）与背景 ≥3:1；文字标牌按 UI AA（≥4.5:1）。
3. **触控 / 交互热区 ≥44×44px**：室内任何可点物体（若世界内有 UI 交互）热区达标。
4. **二楼路径**：楼梯高对比踏面 + 预留坡道（§2.1）。
5. **减少动态**：室内动画（炉火、灯光呼吸）尊重 `prefers-reduced-motion` / 游戏内「动态效果」开关（圣经 §6.3）。
6. **安全动线**：门洞宽度 ≥ 玩家可舒适通过；不出现「视觉上像门实为墙」的假门（直接修正 Bug 3 的二楼不可达）。
