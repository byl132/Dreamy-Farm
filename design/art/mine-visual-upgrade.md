## 0. 总览

### 0.1 目标调性（Design Tone）
矿洞**不是**黑暗恐怖的地下牢笼，而是**被暖光晶体照亮的梦境地下乐园**。
三条不可破的底线，与农场美术方向完全对齐：

1. **圆润柔和非尖锐**——所有轮廓以圆角、低多边形面片、柔边为主；杜绝尖刺、骷髅、血迹等恐怖符号。
2. **暖光主导，冷暗仅作点缀**——用暖金 #FFD28C 晶体光作为主光源；真正「暗」的区域只用于制造层次与探索感，面积不超过单屏 25%，且必有暖光出口暗示。
3. **威胁靠「大/亮/饱和」而非「暗/血/尖」表达**——怪物威胁等级通过体型、辉光强度、色彩饱和度、姿态张度来传递，玩家一眼可分。

### 0.2 全局配色板（Color Palette）

| 角色 | Hex | RGB | 用途 |
|---|---|---|---|
| 暖金强调 (`accent_gold`) | `#FFD28C` | 255,210,140 | 新手引导描边、晶体辉光、下一层路标、角色暖光描边（沿用既有） |
| 暖石灰 (`stone_warm`) | `#B9A896` | 185,168,150 | 矿洞主岩体，偏暖不冷 |
| 深岩 (`stone_deep`) | `#8C7B6B` | 140,123,107 | 阴影面、远景岩层 |
| 柔粉 (`pink_soft`) | `#F4C9D7` | 244,201,215 | 怪物/点缀粉彩 |
| 薄荷 (`mint_soft`) | `#C9E4D4` | 201,228,212 | 怪物/植物点缀 |
| 奶油 (`cream`) | `#FCE8B8` | 252,232,184 | 木质、暖面光 |
| 梦紫辉 (`violet_glow`) | `#C9B6F0` | 201,182,240 | 次级晶体辉光（与暖金形成冷暖对比，不抢主调） |
| 幽影 (`shadow_cool`) | `#2E2A3A` | 46,42,58 | 冷暗区域/雾化底色（克制使用） |

> 配色纪律：单屏暖色（金/粉/薄荷/奶油）占比 ≥ 70%；冷暗 `#2E2A3A` 仅作氛围雾与远处剪影。

### 0.3 通用材质建议（Material Direction）
- **Toon / 柔边着色（Soft Toon）**：使用 2–3 阶明度带 + 轻微边缘光（rim light），避免写实 PBR 的高光锐利感。
- **自发光（Emissive）晶体**：`emissive = accent_gold / violet_glow`，强度 0.6–1.0，作为矿洞唯一「主动光源」。
- **岩体**：`albedo = stone_warm`，叠加低频噪声法线（程序化或 512² 贴图），粗糙度 0.9，无金属感。
- **木质支护**：`albedo = cream` 加深色木纹，保留手作温感。
- **角色/怪物**：matte 哑光，明度带柔和，边缘暖金描边（复用新手引导描边逻辑）。

### 0.4 通用 VFX 建议（VFX Direction）
| VFX | 形态 | 参数建议 | 用途 |
|---|---|---|---|
| 浮尘 (`fx_dust`) | 缓慢上升的半透明微粒 | 尺寸 2–6px，速度 0.2–0.5/s，密度中 | 空间体积感、暖光可见性 |
| 晶体辉光 (`fx_glow`) | 径向柔光 + 轻微脉动 | 脉频 0.5–1Hz，强度 ±15% | 路标、光源、怪物威胁提示 |
| 光柱 (`fx_lightshaft`) | 体积光锥（god-ray） | 从晶体向下，软边缘 | 引导视线、强化「下一层」 |
| 雾 (`fx_fog`) | 指数高度雾 | 颜色 `#3A3142` 偏暖紫，密度低 | 远景收敛、层次 |

## 1. 矿洞玩家角色模型（Mine Character）

### 1.1 视觉目标
与农场角色完全一致的梦幻治愈风，进入矿洞后通过**装备差异化**（矿灯/提灯/护目镜）体现「下矿」身份，而非换一套陌生造型。可读性优先级：剪影辨识 > 暖光描边 > 材质细节。

### 1.2 造型方向
- **比例**：Q 版孩童比例（头身比 ≈ 1:1.2），大圆头、短四肢，最大化亲和力。
- **Silhouette**：圆润胶囊躯体 + 球状头；矿灯在头顶形成独特「小光点」轮廓，远看即可认出是「玩家」。
- **材质**：哑光柔边 toon，明度带 3 阶；边缘暖金 rim light（`accent_gold`，强度 0.4）。
- **配色**：主体奶油 `#FCE8B8` + 薄荷围巾 `#C9E4D4`；矿灯发光 `#FFD28C`。
- **可读性**：始终有一束头顶暖光（提灯/矿灯），保证在暗区也能第一时间定位玩家。

### 1.3 真实资产路径（推荐）
- 资产：`cha_mine_hero`（含矿灯子物体）。
- 复用农场角色骨架与绑定，仅替换/追加下矿装备；动画集：idle、walk、mine_swing（挥镐）、descend（下梯）、happy、hurt（软萌后仰，非血腥）。
- 导出：UrhoX 兼容模型（.mdl / .ani），LOD0≈1.2k 面，LOD1≈400 面。

### 1.4 程序化改进路径（兜底）
若暂无真实模型，用基础几何体组合做到「明显不粗糙」：
- 头：低分段 `CreateSphere`（分段 16+，非 8）套柔边 toon 材质。
- 身：`CreateCapsule` 或圆角 `CreateBox`（倒角参数据引擎支持），避免直角硬边。
- 矿灯：`CreateSphere` + emissive `accent_gold` + 点光源（范围受限，避免性能爆炸）。
- 暖光描边：复用新手引导聚焦描边的后处理/rim 逻辑，给角色加 `accent_gold` 边缘光。
- 动画：用骨骼/节点旋转做 idle 呼吸、walk 上下浮动，替代骨骼动画。

### 1.5 资产清单（Mine Character）
| 资产 ID | 类型 | 规格 | 路径 |
|---|---|---|---|
| `cha_mine_hero` | 角色模型+骨架 | LOD0 1.2k 面 / LOD1 400 面 | `assets/characters/` |
| `cha_mine_hero_lantern` | 子物体（发光矿灯） | emissive gold | 同上 |

## 2. 矿洞怪物模型（Mine Monsters）

### 2.1 视觉目标
**梦幻可爱而非恐怖**。所有怪物保留圆润轮廓与粉彩配色；威胁等级用「体型↑ / 辉光↑ / 饱和↑ / 姿态张度↑」四维编码，玩家 0.5 秒内判威胁。提供 3 种类型，覆盖低/中/高三档威胁。

### 2.2 三种怪物规格

#### 类型 A · 萤光史莱姆 `mon_slime_glow`（低威胁）
- **Silhouette**：半透明果冻 blob，轻微不规则圆顶，无棱角。
- **配色**：粉 `#F4C9D7` 半透明 + 内部 `accent_gold` 微光点。
- **可读性**：最小体型（≈角色 0.6 倍）、最低辉光、最柔——一眼「安全」。
- **姿态/动画**：idle 呼吸缩放；attack 弹跳突进（软萌砸地，无伤害特效夸张化）；defend 压扁；flee 快速弹走。

#### 类型 B · 藤甲甲虫 `mon_beetle_vine`（中威胁）
- **Silhouette**：圆胖甲虫，背覆藤蔓甲壳，六短腿，整体仍圆。
- **配色**：薄荷甲壳 `#C9E4D4` + 藤蔓深绿（非黑），边缘 `accent_gold` 描边。
- **可读性**：中体型（≈角色 1.0 倍）、中辉光、有「壳」暗示防御——「需小心但不致命」。
- **姿态/动画**：idle 甲壳开合；attack 卷成球冲撞（charge）；defend 闭壳；flee 六足快爬撤离。

#### 类型 C · 晶石守卫 `mon_guard_crystal`（高威胁）
- **Silhouette**：大型温石头人，由暖金/梦紫晶体构成，缓慢、厚重，肩胸嵌发光晶。
- **配色**：`stone_deep` 躯体 + `accent_gold`/`violet_glow` 晶体辉光（高饱和高亮）。
- **可读性**：最大体型（≈角色 2.2 倍）、最强辉光、姿态张度最大——「强敌，优先规避」。
- **姿态/动画**：idle 晶体脉动；attack 抬臂砸地（带光柱预警）；defend 晶壳合拢（减伤）；flee 极少（守卫型基本不逃，可用「缩入岩壁」替代）。

> 威胁一致性规则：辉光强度 A<B<C；体型 A<B<C；饱和 A<B<C。颜色本身不表达善恶，只表达「量级」。

### 2.3 真实资产路径（推荐）
- 每类：模型 + 骨架 + 4 套姿态动画（idle/attack/defend/flee）。
- LOD：A≈600 面 / B≈900 面 / C≈1.5k 面；emissive 晶体单独材质通道。

### 2.4 程序化改进路径（兜底）
- A：低分段 `CreateSphere` 压扁 + 半透明 toon + 内部小 emissive 球；弹跳用 Y 轴缩放模拟。
- B：圆 `CreateBox`（倒角）+ 顶部 `CreateSphere` 甲壳 + 藤蔓用细 `CreateCylinder` 缠绕；冲撞用整体位移。
- C：大 `CreateBox`/`CreateCapsule` 堆叠 + 多处 emissive 晶球（`accent_gold`/`violet_glow`）+ 肩胸点光源；砸地用缩放脉冲 + 临时光柱 VFX。
- 通用：给所有怪物加 `accent_gold` rim，威胁越高 rim 越亮；用辉光强度差异直接编码威胁。

## 3. 矿洞内部结构（Mine Internal Structure / Layout）

### 3.1 视觉目标
把「粗糙几何体拼凑的层级下探」升级为**连贯可信的梦境矿穴**：清晰的层级路标、温暖的晶体照明、柔和尘雾氛围、可信的支护/轨道/梯子结构。核心 KPI：**玩家在任何一层都能秒懂「下一层在哪、主路怎么走」**。

### 3.2 空间布局原则（Layout Principles）
1. **节点式分层**：每层（floor）为一个「厅室节点」，由 1 个明确的**下探口（梯子/光井）**连接下一层；避免无方向感的迷宫。
2. **路标唯一化**：每个下探口用「暖金光井 + 光柱 VFX + 梯子」三位一体标记，全矿洞统一符号，绝不随机。
3. **主路暖亮 / 支路冷暗**：主路径始终有晶体照明（暖）；支线/宝箱洞可偏暗（`shadow_cool`），用「暗=可选探索」编码。
4. **视野收束**：用岩体遮挡 + 高度雾，让玩家一次只看清当前节点，避免「全屏粗糙几何体暴露」。
5. **尺度亲切**：廊道宽度 ≥ 角色 3 倍，杜绝压迫感（治愈优先于「矿洞幽闭」）。

### 3.3 结构元素（从粗糙→连贯）
| 元素 | 粗糙现状 | 升级目标 | 建议几何/资产 |
|---|---|---|---|
| 支护木 | 随机 box | 规律排列的拱形木架 | `env_mine_beam`（重复模块） |
| 轨道 | 无 | 暖金/铁灰细轨 + 枕木 | `env_mine_rail` + `env_mine_tie` |
| 梯子/光井 | 裸 box | 发光梯 + 顶部光柱 | `env_mine_ladder` + `fx_lightshaft` |
| 矿车 | 无 | 圆角木质小车（可互动） | `env_mine_cart` |
| 岩体 | 裸 sphere/box | 圆润岩簇 + 低频噪声 | `env_mine_rock`（模块拼贴） |
| 晶体 | 无 | 自发光晶簇（主光源） | `env_mine_crystal` + `fx_glow` |

### 3.4 材质 / 光照 / VFX 建议
- **光照**：以 `env_mine_crystal` 的 emissive 为主光源（每节点 1–3 处），辅以极弱环境光（`shadow_cool` 提亮版）保底可见；禁用强方向性冷光。
- **雾**：指数高度雾，色 `#3A3142` 偏暖紫，密度低，仅用于远景收敛。
- **尘**：`fx_dust` 全局低密度，晶体附近加密，强化「光中有尘」的梦境感。
- **光柱**：每个下探口 1 道 `fx_lightshaft`，向下指引，作为最强可读性信号。

### 3.5 真实资产路径（推荐）
- 模块化 prefab：`env_mine_beam` / `env_mine_rail` / `env_mine_tie` / `env_mine_ladder` / `env_mine_cart` / `env_mine_rock` / `env_mine_crystal`，统一按网格对齐拼接成层。
- 贴图：`tex_stone_warm`(512²)、`tex_wood_beam`(256²)、`tex_crystal_emissive`(256²)。
- 每层用少量模块组合，控制 draw call 与面数预算。

### 3.6 程序化改进路径（兜底）
- 岩体：`CreateSphere` 低分段 + 随机缩放/位移拼贴成圆润岩簇，套 `stone_warm` toon，避免裸 box。
- 支护木：`CreateBox` 圆角（倒角）+ `cream` 木纹材质，按拱形规律排布。
- 轨道：`CreateBox` 细长条重复 + 枕木间隔，材质偏暖灰。
- 下探口：中心 `CreateCylinder` 光井 + emissive `accent_gold` + 1 个点光源 + `fx_lightshaft`（程序化光锥），做成「最亮处即下一层」。
- 晶体：`CreateIcosahedron`/低面球 + emissive，散布节点，兼作光源。
- 关键：靠「发光下探口 + 规律支护 + 暖光尘雾」三大信号，用纯几何 + 材质 + 光照把「粗糙」拉到「可信任的梦境矿穴」。

## 4. 已知限制 / 待主理人确认

1. **真实 3D 资产来源**：`cha_mine_hero`、`mon_*`、`env_mine_*` 等真实模型/贴图是否需要外部美术产出或 AI 生成？当前规格默认「有真实资产时按此落地」，否则走程序化兜底。
2. **程序化改进收益上限**：纯几何 + 材质 + 光照方案可显著消除「粗糙感」并建立可读性，但**无法达到真实模型的表情/动画细腻度**；建议角色与高威胁怪物（C 类）优先拿真实资产。
3. **性能预算待程基岩确认**：晶体 emissive 点光源数量、VFX 粒子密度、每层 draw call 上限需与引擎渲染能力对齐（UrhoX / 目标平台），本规格的「每节点 1–3 光源」为建议值。
4. **是否复用农场角色模型**：若农场角色已有关卡外资产，矿洞角色建议直接复用骨架 + 追加下矿装备，以保视觉一致性与省成本——需主理人确认农场角色资产可用性。
5. **冷暗区域占比**：本规格定「暗区 ≤ 单屏 25%」，若玩法需要更强探索压迫感，可上调但需同步加强暖光路标，避免偏离治愈调性。
