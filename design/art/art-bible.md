## 第 1 节 · 视觉身份与调性

### 1.1 一句话定位
> **温暖、治愈、真实质感的田园生活模拟** —— 让玩家在轻盈灵动的暖阳农场里，感受从播种到丰收的踏实喜悦。

### 1.2 关键词
治愈 · 真实农场 · 暖阳大地 · 毛玻璃质感 · 轻盈灵动 · 丰收喜悦 · 邻里温情

### 1.3 情绪板（文字描述）
为不同界面建立一致但各有侧重的情绪基调，确保整体"暖阳农场"叙事统一：

| 场景 | 情绪 | 视觉构成（文字板） |
|---|---|---|
| **登录页** | 晨光初醒、邀请感 | 165° 天空蓝→沙色→嫩绿渐变；底部波浪田垄剪影；4 个半透明浮动农场元素（🌾🌻🐔🥕）；居中毛玻璃卡，金棕渐变标题。 |
| **主农场** | 晴日耕耘、掌控感 | 顶部天空渐变过渡到暖土与嫩绿；半透顶栏浮于景上；左侧天气/时间/任务毛玻璃面板；中央 4×4 农田网格（泥土肌理 + 作物 emoji）；底部毛玻璃导航 dock。 |
| **商店** | 粮仓集市、丰饶感 | 金棕渐变页头（木质粮仓联想）；暖沙→奶油背景；分类胶囊标签；商品卡（沙底缩略 + 金价签）。 |
| **背包** | 账本收纳、踏实感 | 木色深棕渐变页头（仓库木柜联想）；米灰→奶油背景；物品格矩阵，数量金角标；空格虚线。 |
| **任务中心** | 清新目标、成就感 | 绿深渐变页头（田野联想）；淡绿→奶油背景；任务卡左侧按类型色条；进度条 + 奖励区。 |
| **Toast 提示** | 即时反馈、轻盈 | 深棕浮层卡，白字，自上淡入后淡出。 |

### 1.4 设计原则（评审与日常决策依据）
1. **真实质感优先于卡通夸张**：用毛玻璃、柔和阴影、泥土肌理、渐变天空传达"真实农场"，而非高饱和扁平卡通。
2. **柔和治愈高于强对比**：层级靠留白、柔和阴影与色彩明度差建立，避免生硬描边与硬黑边。
3. **动效为情绪服务、不为炫技**：浮动、弹跳、淡入仅用于强化"鲜活/丰收"反馈，可一键降级（见第 6.3 节）。
4. **语义可跨端识别**：色彩 / 形状 / 文字 / 图标四重编码，不依赖单一通道（见第 8 节）。
5. **一致性高于数量**：少而精的组件语言贯穿全游戏，新界面必须复用既有组件而非另起炉灶。

### 2.5 对比度与可读性规范（WCAG AA，full 评审已核算）
以下为本圣经采用的"文字-底色"组合的对比度（基于 sRGB 相对亮度计算）：

| 组合 | 对比度 | 结论 |
|---|---|---|
| `--brown #3E2723` on `--cream #FDF6E9` | ≈13.0:1 | 正文 AA/AAA ✓ |
| `--brown-light #6D4C41` on `--cream #FDF6E9` | ≈6.9:1 | 辅助文字 AA ✓ |
| `--brown #3E2723` on `--gold #C9A227` | ≈5.7:1 | 金底棕字 AA ✓（主按钮规范） |
| 白字 on `--gold-dark #8B6914` | ≈5.1:1 | 大字号/页头 AA ✓ |
| 白字 on `--green-dark #2E5A3A` | ≈7.9:1 | 任务页头 AA ✓ |
| 白字 on `--wood-dark #5D3A1A` | ≈10.1:1 | 背包页头 AA ✓ |
| `#1565C0` on `#E3F2FD` | ≈5.1:1 | daily 标签 AA ✓ |
| `#7B1FA2` on `#F3E5F5` | ≈6.9:1 | special 标签 AA ✓ |

**规则**
- 正文文字与底色对比 **≥ 4.5:1**；大字号（≥18.66px bold 或 ≥24px regular）与 UI 组件 / 图标 **≥ 3:1**。
- 禁止在浅底使用低对比文字（如浅灰正文）；辅助文字最低用 `--brown-light`。
- 所有状态（进度、任务完成、作物成熟）必须**同时**有颜色 + 图标/文字/动效编码（见第 8 节）。

### 2.6 ⚠ 生产修正（原型对比度缺陷，Phase 3 前必须修）
| 项 | 原型现状 | 风险 | 本圣经修正 |
|---|---|---|---|
| weekly 标签文字 | `#F57F17` on `#FFF8E1` ≈ **2.5:1** | 不达标（<4.5） | 文字改 `#E65100` on `#FFF3E0`（≈3.6:1，大字号达标；小字号建议加粗或再加深至 `#BF360C`） |
| 警示橙缺失 | 原型无独立 warning 色 | 警告态无专属色 | 新增 `--warn #E65100`（见 2.3），不与 gold 混淆 |
| 稀有紫小文字 | `#E040FB` 直接作文字 ≈3.3:1 | 小字不达标 | 紫仅作光效；文字统一 `#7B1FA2` |
| 能量蓝图标 | `#42A5F5` emoji 着色 on 白 chip | 作为图标 OK（3:1 图标达标） | 保留为图标色；蓝底文字用 `#1565C0` |

### 2.7 ★ 暗色模式考量（可选演进，不阻塞基线）
暖阳浅色为正式基线。若 Phase 3+ 引入暗色模式，遵循"反相暖调"策略，保持品牌温度：
- 底色：`--brown #3E2723` / `--wood-dark #5D3A1A` 作页面底；卡片用 `rgba(255,255,255,0.06)` 毛玻璃。
- 文字：奶油 `--cream` / `--sand` 作正文与辅助。
- 品牌色保留 gold / green 作为强调，但降低饱和度投影。
- 所有对比度须重新按 2.5 核算达标。Phase 1 不实现，但在主题系统预留"浅/暗"双 token 切换点。

## 第 3 节 · 字体与排版

### 3.1 字体族（多端 fallback 链）
- **中文优先**：`"PingFang SC"`（iOS/macOS）→ `"Microsoft YaHei"`（Windows）→ `"Noto Sans SC"`（Android / Web 跨平台兜底）。
- **英文 / 数字**：`system-ui` / `-apple-system` 族，与中文同链。
- **Unity 落地**：WebGL 用 WebFont（Noto Sans SC woff2，子集化）；iOS/Android 原生调用系统中文族；资源数值启用 `tabular-nums` 等宽数字对齐。

### 3.2 字号阶梯（Type Scale）
基于 4/8 节奏与 1.2–1.25 比例，固化以下阶梯，命名 `--fs-*`：

| Token | 字号 | 字重 | 行高 | 典型用途 |
|---|---|---|---|---|
| `--fs-caption` | 11px | 600 | 1.4 | 角标、timer、日期、进度文字 |
| `--fs-small` | 12px | 600/700 | 1.4 | 面板标题、tab、芯片、任务标签 |
| `--fs-body-sm` | 13px | 400/600 | 1.5 | 说明、副信息、列表项 |
| `--fs-body` | 14px | 400/700 | 1.5 | 卡片正文、按钮文字、输入框 |
| `--fs-body-lg` | 15px | 400/700 | 1.5 | 登录副标题、导航文字 |
| `--fs-subhead` | 16px | 700 | 1.4 | 任务卡标题、玩家名 |
| `--fs-title` | 22px | 800 | 1.2 | 页面标题（商店/背包/任务） |
| `--fs-display` | 32–42px | 800 | 1.1 | Logo、主数字（时间/等级） |

### 3.3 字重规范
`400 Regular` / `500 Medium` / `600 Semibold` / `700 Bold` / `800 Heavy`。
- 正文 400；强调数字与标签 600–700；标题与 Logo 700–800。
- 中文避免 300（细体在低密度屏发虚），最低 400。

### 3.4 排版规则
- **行高**：标题 1.2、正文 1.5、描述/说明 1.4。
- **中英混排**：数字与英文使用 `tabular-nums`，资源数值（如 `12,580`）右对齐、等宽，避免位数变化时抖动。
- **字间距**：中文标题 `letter-spacing: 2–4px`（Logo 4px）；正文不额外加字距。
- **截断**：长文本用 `ellipsis` 单行截断（如 plot-label），多行说明最多 2 行截断（见原型 `.item-desc`）。
- **禁用**：全大写英文仅用于小标签（panel-title），正文保持大小写自然。

## 第 4 节 · 构图与栅格

### 4.1 双基准画布（多端）
| 形态 | 基准分辨率 | 安全区（Safe Area） | 主画布缩放策略 |
|---|---|---|---|
| 桌面横屏 Web | **1920×1080** | 左右 0（满宽）、上下 0；内容最大宽 1280 居中 | Canvas Scaler: Scale With Screen Size，Match=0.5（宽高兼顾） |
| 移动竖屏 iOS/Android | **1080×1920**（逻辑约 375×812 @3x） | 顶部 ≥44px（刘海）、底部 ≥34px（Home 指示条）、左右 ≥16px | Match 偏高度（0.7–1.0），避免横向溢出 |

> 设计稿以 1080×1920（移动竖屏）为**主基准**（农场游戏移动优先），1920×1080 为桌面适配基准。两套统一走第 9 节 9-slice / Atlas 流程。

### 4.2 栅格系统
- **桌面**：12 列栅格，列间距 24px，内容区最大宽 1280px 居中，两侧留白。
- **移动**：4 列（窄屏）/ 6 列（宽屏），栅格间距 12–16px，满宽含安全边距。
- **关键布局骨架**（主农场页）：顶栏（固定，半透浮层）→ 主体（桌面：左 200px 侧栏 + 右主区；移动：侧栏隐藏，主区满宽）→ 底栏 dock（固定，毛玻璃）。
- **响应式断点**：`max-width: 768px` 为移动阈值——侧栏隐藏、农田网格 4→3 列、商店 2 列、背包 4 列（固化原型 `@media`）。

### 4.3 间距系统（4/8 倍数，禁止非常规值）
基准单位 4px，常用阶梯：**4 / 8 / 12 / 16 / 20 / 24 / 32 / 48**。
| 场景 | 取值（固化原型） |
|---|---|
| 组内元素间距 | 4–8px |
| 卡片内边距 | 14–20px（面板 14、商品 16、任务卡 18–20） |
| 区块间距 | 12–16px |
| 页面左右边距 | 桌面 24px / 移动 16–20px |
| 登录卡大留白 | 48px 56px（上下/左右） |

### 4.4 安全区规范（移动端必读）
- **iOS**：顶部避让刘海 ≥44px、底部 Home 指示条 ≥34px；打孔屏（Android）顶部 ≥24px。
- 顶栏与底栏必须**内缩**安全区（用 `SafeArea` / `Screen.safeArea` Insets），不可贴边。
- 浮动装饰（登录页 🌾 等）避开安全区与中央交互区，装饰性 opacity≤0.6。

### 4.5 圆角阶梯（固化原型 radius token）
`--radius-sm 8` / `--radius-md 14` / `--radius-lg 20` / `--radius-xl 28`。
- 芯片/胶囊 20（radius 20）；按钮 md(14)；卡片 lg(20)/xl(28)；输入框 md(14)；进度条 4。
- 禁止出现非阶梯圆角（如 10px、18px），保证统一手感。

## 第 5 节 · 图标与插画风格

### 5.1 Emoji 使用策略（阶段化，关键决策）
原型大量使用系统 emoji（🌾🐔🍅 等）。正式规范采用**两阶段混用策略**：
- **原型 / 早期（当前）**：系统 emoji 作为**正式轻量图标**直接使用——跨平台一致、零生产成本、契合"治愈真实"调性。用于：资源芯片图标、作物/动物缩略、浮动装饰、任务类型标记。
- **生产期（美术资产到位后）**：**关键语义图标替换为自绘资产**（见 5.2），emoji 保留用于"作物、动物、情感表达"等叙事性装饰，不再承担精确品牌/操作语义。
- **永远不让 emoji 承担**：① Logo 主识别；② 主操作按钮的唯一图标；③ 需要像素精确对齐的 UI 控件。这些必须自绘。

### 5.2 自绘线性图标风格
- 描边 1.5–2px（@1x 视框 24×24，视觉区 20）、圆角端点（round cap）、无填充或极浅填充。
- 颜色：默认 `--brown #3E2723`，激活/强调用 `--gold` 或 `--green`；禁用纯黑与荧光色。
- 网格对齐：24×24 基准网格，关键节点贴网格（2px 步长）。
- 风格词：干净、圆润、亲和、与毛玻璃卡片调和。

### 5.3 插画与作物视觉
- 色调严格取自第 2 节色板（暖阳大地）；作物插画用扁平+轻微立体（底部内阴影 `inset 0 -8px 12px`），emoji 作占位时可加 `drop-shadow(0 2px 4px rgba(0,0,0,0.3))` 提升质感（固化原型 `.plant-stage`）。
- 插画统一圆角（与组件一致），避免硬边剪纸风破坏治愈感。

### 5.4 多端图标分辨率策略
- 提供 **@1x / @2x / @3x** 三档位图（移动）；Web 优先矢量（SVG / Unity 用矢量栅格化或矢量纹理）。
- 推荐输出尺寸：UI 图标 24 / 48 / 72 / 96 px；主缩略图（作物/商品）144 / 288 px；大图（登录装饰）256+。
- 命名见第 9.6 节（`icon_<name>_<size>`）。

## 第 6 节 · 动效与过渡原则

### 6.1 时长规范
| 类别 | 时长 | 示例 |
|---|---|---|
| 微交互（hover/按压/焦点） | 150–200ms | 按钮按压、图标缩放 |
| 常规过渡（卡片悬浮、状态切换） | 300ms | 卡片上浮、芯片激活 |
| 页面切换 | 400ms | 淡入 + 缩放 |
| 强调动效（收获弹跳、Toast） | 500–600ms / Toast 总 3000ms | 作物 bounce、Toast 进出 |

### 6.2 缓动曲线（固化）
- **标准出场 / 浮现**：`cubic-bezier(0.16, 1, 0.3, 1)`（柔和回弹、ease-out 感）——用于卡片浮现、页面进入、弹层。
- **标准过渡**：`cubic-bezier(0.4, 0, 0.2, 1)`（ease-in-out）——用于颜色/位置过渡、进度填充。
- **无限循环**（浮动/呼吸）：`ease-in-out` 对称，避免加速突变。

### 6.3 ★ 可降级（减少动态效果，`prefers-reduced-motion`）
- **系统级开关**：尊重平台"减少动态效果"偏好（iOS 辅助功能 / Android / Web `prefers-reduced-motion`）。Unity 侧通过 `QualitySettings` 或玩家设置"动态效果"开关统一控制。
- **降级规则**：关闭浮动（login 装饰静止）、关闭弹跳/呼吸（作物 ready 态改静态高亮）、关闭缩放位移（仅保留 ≤200ms 淡入淡出与必要状态反馈）、页面切换改为纯淡入（无 scale/slide）。
- **不可降级**：必要状态反馈（焦点环、错误提示、进度变化）须保留，但以静态/极简形式呈现。

### 6.4 核心动效清单（实现基线）
1. **页面切换**：`opacity 0→1` + `transform scale(0.98→1)`，400ms 标准出场；退场 `translateX(-30px)` + 淡出。
2. **收获弹跳**：作物 ready 态 `bounce` 无限（translateY -5px，1s）；收获瞬间 `scale(0.9)` 收缩后复位为空地。
3. **Toast**：`toastIn`（上移淡入 300ms）→ 停留 → `toastOut`（上移淡出 300ms，于 2.7s 触发），总 3s 自动移除。
4. **卡片悬浮**：`translateY(-3~4px)` + 阴影加深（--shadow→--shadow-deep），300ms。
5. **按钮按压/激活**：主按钮 hover `translateY(-2px)` + 金光增强；激活态金渐变填充（dock active）。
6. **进度条填充**：`width` 过渡 500ms 标准过渡曲线。
7. **浮动装饰**：login 4 元素 `float`（translateY -10px，4s ease-in-out 无限，错位 delay）。
8. **任务点脉冲**：活跃任务点 `pulse`（opacity 1↔0.4，1.5s 无限）。

### 8.1 目标分级

2. **触控目标 ≥44×44px**：★ 原型 `icon-btn` 视觉 38px **不达标**——视觉可保持 38，但**热区/最小可点区域须 ≥44px**（加透明 padding 或布局留白）。所有按钮、芯片、dock 项、农田格均须满足。

5. **色彩非唯一信息通道**：状态不只靠颜色——作物 ready 有 bounce + 金边 + label；任务完成有图标✅ + 文字"已领取" + 透明度；类型有图标 + 文字标签。

## 第 9 节 · 资产生产规范与交付格式（Unity 多端）

### 9.1 UI 画布与缩放（Unity UGUI 建议）
- **Canvas Scaler**：`Scale With Screen Size`；Reference Resolution 双基准（见 4.1）。
- **Match 值**：桌面 0.5（宽高兼顾）；移动竖屏 0.7–1.0（偏高度，防溢出）。
- **锚点（Anchors）**：顶栏/底栏贴边 + SafeArea 内缩；农田网格居中自适应；侧栏桌面显示、移动隐藏（`CanvasGroup` + 布局开关）。
- **SafeArea**：用 `Screen.safeArea` 或 Unity `SafeArea` 组件包裹顶/底栏。

### 9.2 多分辨率交付
- **移动**：逻辑基准 `@1x`（如 375×812），输出 `@2x`（750×1624）、`@3x`（1125×2436）；Android 另按 `mdpi/hdpi/xhdpi/xxhdpi/xxxhdpi` 密度桶。
- **桌面 WebGL**：以 `@2x` 为生产分辨率（视网膜清晰），UI 用矢量/Sprite 缩放。
- **规则**：同一资产三档位图同源导出（同一源文件 100/200/300%），禁止分别手绘导致不一致。

### 9.3 图集（Sprite Atlas）
- **分组**（按页面/功能，避免跨页大图集，控制 draw call）：
  `atlas_common`（通用控件）、`atlas_login`、`atlas_main_farm`、`atlas_shop`、`atlas_inventory`、`atlas_quests`、`atlas_icon`（全图标）。
- **设置**：开启 `Tight Packing` + `Allow Rotation`；`Padding 2–4px`；单图集尺寸 **≤2048×2048**（移动内存友好）。
- **Include in Build**：公共图集常驻，分页图集按需加载/卸载。

### 9.4 九宫格（9-Slice）
- 以下组件背景/底图必须用 9-slice，避免拉伸模糊：卡片背景、按钮、输入框、面板、dialog、进度轨道、dock 底。
- **边框区**：8–16px（与圆角阶梯匹配）；中心区可拉伸。Unity 中用 `Image.type=Sliced` + 正确 `Border` 值。
- 命名 `9slice_<name>`（见 9.6）。

### 9.5 SpriteSheet / 序列帧
- 作物 4 阶段生长、收获特效、漂浮粒子、按钮按压帧使用 SpriteSheet。
- **网格规范**：统一单元 **128×128**（含 4px 透明边距），逐帧 `crop_<name>_stage1..4`；动画在 Unity `Animator` / `SpriteSkin` 驱动。
- 导出：单张大图（如 512×512 含 4×4 帧）+ 配套 `.meta` 帧定义，或 Unity 内 `Sprite Editor` 切片。

### 9.6 命名规范（强制，snake_case 全小写，下划线分隔，禁空格/中文）
| 类别 | 模板 | 示例 |
|---|---|---|
| UI 组件（按状态） | `ui_<page>_<component>[_<state>]` | `ui_main_btn_primary_pressed` / `ui_shop_card` |
| 图标 | `icon_<name>_<size>` | `icon_settings_48` / `icon_gold_96` |
| 作物 | `crop_<name>_<stage>` | `crop_tomato_stage4_ready` / `crop_wheat_seed` |

| 九宫 | `9slice_<name>` | `9slice_card_lg` |
| 序列帧 | `anim_<name>_<frameNN>` | `anim_harvest_03` |
| 背景/渐变贴图 | `bg_<scene>[_<variant>]` | `bg_login_sky` |
| 通用 | `<category>_<descriptor>_<variant>_<size>` | `fx_float_decor_256` |

### 9.7 导出格式与压缩
- **格式**：PNG（RGBA，保留透明）；UI 资产默认 **关闭 mipmap**（防模糊），3D/世界空间资产开 mipmap。
- **色彩空间**：sRGB；UI 贴图 `Alpha Is Transparency=true`。
- **纹理压缩**：
  - 移动（iOS/Android）：**ASTC**（推荐 `ASTC 6x6` 平衡质量/体积）。
  - 桌面 WebGL：**BC7**（DXT）/ 或 ASTC（Unity WebGL2 支持）。
- **美术风格贴图**（若有手绘纹理）：保留较高 bitrate，避免压缩块效应破坏"真实质感"。

### 9.8 资产预算与性能（多端）
- **UI 纹理内存预算**：单页活动图集 ≤ **8MB**；全局常驻（common+icon）≤ **16MB**；总 UI ≤ **30–50MB**（移动中端机）。
- **Draw Call**：合并同图集 UI；毛玻璃（backdrop blur）在 Unity/WebGL 移动端**代价高**——★ 建议降级为半透纯色 + 预烘焙模糊贴图（见 7.1），或在低端机关闭 blur。
- **Overdraw 控制**：半透毛玻璃层不宜堆叠 >2 层；登录页装饰 opacity≤0.6 且 `pointer-events:none`。
- **图集碎片**：定期审计孤立资产（无引用的 sprite），见 Phase 资产审计流程。

### 10.3 材质与贴图（引擎 = UrhoX / TapTap Maker）
- **源格式**：PNG（RGBA，sRGB），保留透明。
- **交付压缩**：优先 **KTX2（Basis Universal）**——单一文件跨端（Web/iOS/Android）可转码；平台回退：Android ETC2（基线）/ ASTC（高质量），iOS ASTC / PVRTC。
- **mipmap**：世界/3D 资产**开 mipmap**；UI 贴图关 mipmap（与 §9.7 一致）。
- 材质类型：引擎 Lit/Standard 等效；albedo + normal + roughness/AO；顶点色/贴花做细节，避免逐物建模。
- ⚠ Phase 3 与 engineering-lead 最终确认 UrhoX 贴图管线与导出目标。

### 10.4 地形/地面（详见 interior_art_direction.md §1）

- LOD：Base/LOD1/LOD2 + 剔除，贴图按设备档位切换。

### 10.5 建筑与室内（详见 interior_art_direction.md §2，已据 B3/B4 finalize）
- **主屋九区视觉身份（已锁死）**：一楼生活层 A 客厅 / B 餐厨 / C 壁炉 / D 储藏工坊 / E 楼梯井；二楼自我层 F 卧室 / G 书房 / H 陈列 / I 楼梯平台。配色/材质/家具/灯光见 interior 文档 §2.2 表。
- **风格**：木结构 + 灰泥墙 + 暖光；圆润无硬边，呼应 UI 圆角阶梯。一楼明亮开放、二楼私密低照度，两级光环境对比即分区叙事。
- **硬约束（几何取证）**：二层家具避开烟囱槽 x∈[-0.35,0.35]；高家具（衣柜/陈列架）不贴最外侧斜顶墙；右后漏光缝 x∈[7,8] z∈[-5.5,-1] 做灯光过渡。
- **二楼可达**：Floor-as-Scene（交互点切场景，非爬楼），保留禁入盒防穿模（修正 Bug 3）。
- **集市建筑（修正 Bug 2，三级制）**：摊位 L0 就地交互（不做室内）；4 栋空壳建筑（酒馆/诊所/花房/村公所）补 L1 室内，各含不可替代玩法目的，材质偏「商用/仓储」（木+麻绳+石 `--stone`）；主屋/酒馆/村公所为 L2 多区。详见 interior 文档 §3.5。
