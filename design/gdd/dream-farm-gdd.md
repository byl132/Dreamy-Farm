## 1. 游戏支柱（Pillars）

本作是**二次元田园生活模拟 RPG**（Stardew 风格），目标用户 15–25 岁女性（"她经济"）。以下 5 条支柱（**设计取舍的单一事实基线 SSOT**；较概念文档 4 支柱的演进见 G8 裁定）是后续所有设计取舍的标尺，彼此独立、不重叠：

| # | 支柱 | 一句话 | 阐释（取舍标准） |
|---|------|--------|------------------|
| P1 | **可信田园经营** | 肥力 / pH / 连作 / 突变 / 天气 / 病虫害构成真实可读的生长因果。 | 种田不是点击放置，而是"土壤—气候—照料"的系统模拟。当有人提议"简化掉土壤/pH"时，本支柱说**保留可读模拟**。 |
| P2 | **情感陪伴与轻社交连接** | 10 位二次元 NPC 的好感/对话/节日/礼物（情感核心）+ 邻居/偷菜/互访（轻社交连接）。 | 对应"她经济"定位与用户画像；吸收概念 P4「轻社交连接」。当范围吃紧时，本支柱**保护 NPC / 对话 / 节日 / 偷菜邻里**预算；当有人提议 PvP / 排行榜羞辱时，本支柱说**不**。 |
| P3 | **成长与终章叙事** | 5 章主线推进 + 世界树终章，提供清晰的进程感与通关目标。 | 等级 / 解锁 / 地区 / 世界树构成长线 spine。当有人想无限堆内容而模糊终点时，本支柱说**守住"世界树绽放"的通关承诺**。 |
| P4 | **探索与收集** | 矿洞 / 森林 / 遗迹 / 钓鱼 / 作物突变 / 图鉴，提供可选的长线驱动。 | 对应 Explorer 型玩家与"发现"趣味。探索应为**可选深度**，不阻塞主线。 |
| P5 | **自我表达与从容节奏** | 农场是玩家的画布——布局/装饰/主题表达个性（恢复概念 P3「自我表达」为显式驱动）+ 时间/季节/低惩罚基调让玩家在任何节奏下放松经营。 | 装饰/室内/布局系统 = 钻石核心 sink（MONET-01 营收载体），本支柱**保护装饰与布局预算**；体力归零只是"晕倒丢部分钱"，无永久失败。当有人提议"加硬核失败惩罚"或"砍掉装饰系统"时，本支柱说**不**。 |

> **支柱自检**：P1/P5 共同排除"填鸭式 / 硬惩罚"；P2（情感陪伴+轻社交）/ P3 / P4 共同要求系统具备"关系深度 / 进程终点 / 可选探索空间"；P5（自我表达+从容）要求装饰/布局系统获得支柱级预算保护。五条合起来定义了本作边界——**一个真实、温柔、可表达、有终点、可探索、可轻连接的田园 RPG**，而非纯放置或纯战斗游戏。

> **支柱调和裁定（G8 · P6-DES-IMPL）**：本 5 支柱集为设计取舍的 **SSOT**（已裁定、已落地代码、更具体）。较概念文档 4 支柱的三处真分歧按**方案 A** 收口：① 恢复「自我表达」为显式 P5（装饰=钻石核心 sink，给 MONET-01 营收背书）；②「轻社交连接」并入 P2；③ 概念「Narrative 弱 / 不做主线」被 GDD P3 终章叙事**升级裁定**覆盖（世界树/5 章已落地，无法回退）。概念 4 支柱即日起被本 SSOT 取代，详见 `design/concept/dream-farm-concept.md` 顶部 G8 标注；相关工作 `production/phase6-sprint/econ-gdd/G8-pillars-reconcile.md`。

## 2. 核心循环 + 次要循环

### 2.1 核心循环（Core Loop）

```
开垦土地 → 购买/获得种子 → 播种 → 浇水(每日) → 等待真实生长(受肥力/pH/天气/连作影响)
   → 收获(品质由照料决定) → 出售赚金币 → 买更好种子/工具/动物 → 升级农场
        ↑________________________________________金币回流___________________________________↓
```

**时间锚点**：1 游戏天 = 20 分钟真实时间；1 年 = 4 季 × 28 天 = 112 天；每日 6:00 起床，2:00 强制睡觉（体力耗尽则晕倒）。每天 0 点结算作物生长、NPC 日程、商店库存。

### 2.2 次要循环（Secondary Loops）

| 循环 | 内容 | 支撑支柱 |
|------|------|----------|
| **社交循环** | 与 NPC 对话 / 送礼 / 参加节日 → 好感提升 → 解锁剧情/折扣/隐藏内容 | P2 |
| **养殖循环** | 购动物 → 每日喂食/收集产物(蛋/奶) → 出售 → 扩栏 | P1/P3 |
| **探索循环** | 进入矿洞/森林/遗迹 → 采集/战斗/解谜 → 获得矿石/稀有物/四季之种 | P4 |
| **钓鱼循环** | 钓鱼小游戏 → 鱼类/稀有事件 → 出售或送礼 | P4 |
| **剧情循环** | 5 章主线任务 → 等级与区域解锁 → 世界树终章通关 | P3 |
| **世界树终章** | 集齐 4 季之种 → 农场中央 3×3 地块 7 天照料 → 绽放通关 | P3 |

### 2.3 MDA 框架（以真项目为准）

- **Mechanics（机制）**：地块状态机(荒地→已开垦→已浇水→生长中→成熟)、土壤属性(肥力/水分/pH/杂草/污染/连作)、6 阶段作物生长、品质(普通/银星/金星/铱星)、4 病害+4 虫害、9 类天气、5 地区气候、时间/季节/日夜、体力、背包/商店/金币、任务(主线/支线/每日)/成就、NPC 好感/日程、钓鱼/矿洞/遗迹/动物、世界树。
- **Dynamics（涌现）**：玩家形成"每日巡回"（浇水→收获→卖→买→做任务）；为品质而"精耕细作 vs 广种薄收"的权衡；为节日/Buff 调整播种节奏；矿洞"下多层 vs 体力预算"的风险博弈；NPC 好感驱动的重玩。
- **Aesthetics（目标趣味）**：**Submission（放松）** + **Fellowship（陪伴）** 为主；**Discovery（发现/突变/遗迹）** + **Expression（农场布局/装饰）** 为辅；轻量 **Challenge（矿洞战斗）** 作为可选刺激；基本排除硬核对抗（Killers）。

### 2.4 动词优先法（Verb-first）

| 动词 | 玩家做什么 | 支撑支柱 | 代码落点 |
|------|------------|----------|----------|
| **种植 Cultivate** | 选种→开垦→播种→每日浇水→等生长 | P1/P5 | CropSystem / SoilData |
| **收获 Harvest** | 点击成熟作物→入背包→正反馈 | P1 | CropSystem / SaveSystem |
| **经营 Trade** | 买种子/卖产物/升级 | P1/P3 | FarmConfig / SaveSystem(金币) |
| **陪伴 Bond** | 对话/送礼/过节提升好感 | P2 | NpcSystem / DialogueSystem / FestivalSystem |
| **探索 Explore** | 矿洞/森林/遗迹采集战斗解谜 | P4 | ExploreSystem / MineGenerator / FishingSystem |
| **培育 Grow（终章）** | 集四季之种→照料世界树 | P3 | WorldTreeSystem |

### 2.5 玩家心理学

- **自我决定论（SDT）**：**自主**——自由种什么/是否社交/如何布局；**胜任**——等级/成就/图鉴/世界树提供可见 mastery；**关联**——NPC/邻里/节日提供归属感。
- **心流**：基调 cozy（P5 低惩罚），但矿洞战斗/体力预算提供"可选挑战"维持心流下限；分层目标（每日→章节→世界树）防止无聊。
- **Bartle**：**成就者**（主线/成就/图鉴，主力）、**探索者**（矿洞/遗迹/突变）、**社交者**（NPC/偷菜/邻里）为主要服务；**杀手**仅以轻量矿洞战斗触及，非核心、不服务 PvP。

## 4. 经济系统（金币 / 钻石 / 体力 / 等级 / 商店 / 背包）

> **双币经济裁定（C11 + P6-DES-IMPL 实施轮）**：采用 F2P 混合变现，双货币 = **金币（软通货·earned）** + **钻石（硬通货·premium）**。钻石此前在 v0.2 基线中零定义，本修正案补全其 source/sink 与受控转换（回写自 `production/phase6-sprint/econ-gdd/` 草案 GDD-ECON-01 / MONET-01 / BAL-01，已裁定升为正式定义）。

### 4.1 金币（软通货·earned）
- **权威字段**：`game.gold`（EconomyManager 统一入口 `Earn/Spend/CanAfford`）。**单一权威**，禁止任何玩法/奖励代码写 `GameState.game.money` 或 `saveData.player.money`（金币单一权威 ADR：`docs/architecture/ADR-001-currency-authority.md`；工程约束见 `design/architecture/ADR-001-game-state.md` 防 `.money` 回归）。
- **Source（产出闭环）**：作物(10–200)/动物产物(50–300)/鱼(30–500)/矿石(20–400)/任务奖励(50–600)/公告板悬赏(100–300)。品质倍率放大售价（普通 1.0× → 铱星 2.0×，C7 裁定；⚠️ 与 GAMEPLAY_OVERVIEW "1.0×~3.5×" 不一致，以 C7 为准）。
- **Sink（消耗闭环）**：标准种子(5–50/粒)、工具/建筑升级(50–2000，阶梯)、动物购买(200–2000)、诊所体力(100 金→+100 体力，每日≤3 次)、扩地/建筑升级(300–5000，阶梯)。无无限 faucet，软 sink 随进度阶梯放大吸收盈余。

### 4.2 钻石（硬通货·premium · 新增定义）
- **权威字段**：`game.diamond`（新增，复用 EconomyManager 范式 `EarnDiamond/SpendDiamond`；存档单向镜像 `saveData.player.diamond = game.diamond`）。
- **Source（来源）**：
  | 来源 | 数额 | 节奏 | 是否付费 |
  |------|------|------|----------|
  | IAP 直购 | 60 / 390 / 900 / 1950 / 5250（含赠送档） | 随时 | 是 |
  | 赛季通行证·免费轨 | ~30 钻 / 28 天 | 每日/周发放 | 否 |
  | 赛季通行证·付费轨 | ~400 钻 + 装饰 + 溢价作物 + 主题 | 每赛季 | 是（买轨） |
  | 去广告订阅 | +5 钻/日 常驻补贴 | 订阅期每日 | 是（月费） |
  | 激励视频 | +3 钻/次，≤5 次/日（≤15 钻/日） | 玩家主动 | 否（看广告） |
  | 首次成就 | 50–100 钻（一次性） | 解锁即发 | 否 |
  | 每日登录里程碑 | 偶发小额 | 月度循环 | 否 |
  > **F2P 微量钻石下限**：激励视频(≤15/日) + 赛季免费轨(~1/日) ≈ **16–20 钻/日**，月均 ~500–600 钻——足以买少量装饰/加速，**无硬付费墙**。
- **Sink（消耗）**：
  | Sink | 价格点（钻） | 类别 | 是否卡进度 |
  |------|--------------|------|-----------|
  | 溢价作物种子（玫瑰等） | 15/粒 | 溢价作物 | 否（金币作物等价替代） |
  | 装饰物（P5 自我表达载体） | 20–300 | 装饰 | 否 |
  | 加速（跳过生长/即时收获/体力瞬回） | 2–20/次 | 便利 | 否（时间可等价获得） |
  | 赛季通行证付费轨 | 68 钻 或 ¥30 | 通行证 | 否 |
  | 主题/皮肤 | 30–200 | 装饰 | 否 |
  | 扩背包格/扩地块 | 30–200 | 容量 | 否（可金币扩基础档） |

### 4.3 双币转换（受控·单向·硬上限）
- **仅钻石→金币**，经"游商/流浪商人"每日限额兑换；**禁止金币→钻石**（防止 earned 金 farming 转硬通货破坏 IAP）。
- **兑换率**：`1 钻 = 100 金`（刻意偏低，约 IAP 价的 1/10 效率）。
- **每日硬上限（已裁定 · 不可放开）**：**30 钻/日 = 3000 金/日**。定位"应急阀门"（缺钱买种兜底），非主路径；封死通胀，保护 P5 不被 pay-to-skip。
  ```
  convertOut(gold) = min(DAILY_CAP, reqDiamond) × RATE
                   = min(30, reqDiamond) × 100      // 单位：金
  ```
- **通胀护栏**：品质倍率硬顶 2.0×（C7）；转换日上限 30 钻；软 sink 随进度阶梯放大；无无限金币 faucet；突变率护栏 2%/收（CROP-02）。

### 4.4 经济设计红线（C11 + P5 从容节奏）
1. **无硬付费墙**——所有主线进度内容可用「金币 + 时间」获得；钻石只买便利/装饰/溢价作物。
2. **无能量惩罚**——钻石**不卖体力**；体力补用金币（诊所 100 金，见 §4.1）。
3. **钻石 sink 不卡主线**——加速/装饰是 optional convenience，非解锁门槛。
4. **金币单一权威**——`game.gold`（EconomyManager）为唯一写入目标（见 §4.1）。

### 4.5 体力 / 等级 / 商店 / 背包（沿用 v0.2）
- **体力**：上限 100（部分等级提升）。消耗：开垦 −2 / 种植 −1 / 浇水 −1 / 钓鱼 −5 / 下矿 −3 层 / 战斗 −5。恢复（四路径差异化定价，防主导策略）：睡觉 +100（1/日，免费）/ 料理 +20~50（耗材金购）/ 诊所 +100（100 金，每日≤3 次）/ 钻石加速瞬回（5–20 钻，≤10/日）。归零→晕倒回家、丢失部分金钱（轻惩罚，呼应 P5）。
- **等级**：Lv.1→Lv.20（✅ 路线 B：上限 20，2026-08-05 裁定；与 `main.lua` `MAX_LEVEL=20` 对齐），经验累计阈值 0→14000（见第 5.1 章表），每升 1 级体力上限 +10（Lv.20 时上限约 290）。
- **商店**：NPC 商店买卖种子/物品/工具/动物；村公所公告板每日悬赏；周刷新特价；**钻石店**（溢价作物/装饰/加速/主题）与金币店分栏。⚠️ 代码无独立 `ShopSystem` 模块，仅有已废弃 `shop.lua`(301) + `FarmConfig` 商店物品——属文档(架构列 `ShopSystem`)与代码缺口。
- **背包**：分类（种子/作物/工具/材料/料理/鱼），堆叠上限（种子 99 / 作物 999 / 工具 1 / 材料 999 / 料理 99 / 鱼 99），由 `SaveSystem` 管理。
