# 设计规格：A-10 偷菜玩法与视觉风格（spec-A10-steal-crop）

- **关联**：bug-triage **A-10「多合一 #3」** 子项「偷菜页面风格 | 设计 | 交 art-director（非本次工程）」。
- **代码核查**：`scripts/gameplay/StealCropSystem.lua`（规则引擎）、`scripts/social/StealCropNetwork.lua`（云端同步）、`scripts/social/FriendSystem.lua`（入口）、`scripts/visit.lua`（2D 拜访场景，偷菜发生处）。
- **类型**：纯设计，不改码。日期 2026-08-05。

---

## 1. 背景

偷菜的**规则引擎、云端同步、好友入口、2D 拜访场景**均已存在（`StealCropSystem` / `StealCropNetwork` / `FriendSystem` → `openStealVisit` / `visit.lua`）。triage 将「偷菜页面风格」判为**设计项**。当前缺口 = ① 玩法规则定稿（边界/平衡确认）与 ② **视觉风格 + 受害者侧「被偷提示」**（代码完全缺失）。

---

## 2. 设计原则（对齐 P1 治愈 / 关联）

**「互助优先、轻偷菜」**：偷菜为小收益 + 轻好感惩罚；互助（浇水/施肥）为正循环。**给被害者非惩罚性反馈 + 可选防护（自主 / SDT）**，避免「开心农场」式 toxic，守住治愈基调。

---

## 3. 偷菜玩法规则（基于 `StealCropSystem.CONFIG` 定稿）

| 维度 | 规则 | 代码常量 |
|---|---|---|
| 触发条件 | 好友列表「偷菜」→ `openStealVisit` 进入 2D 拜访场景；作物 `isMature` 且未 `stolen`、未处保护期/防护栏 | — |
| 可偷范围 | 仅成熟未偷过的作物；`isProtected`/栅栏内不可偷；每好友每日最多被偷 1 次 | `MAX_STEAL_PER_FRIEND = 1` |
| 冷却 / 保护期 | 作物成熟后 2h 内不可偷；每日偷菜总次数上限 3 | `PROTECTION_HOURS = 2`、`MAX_STEAL_PER_DAY = 3` |
| 收益 | 产量 × 30%，下限 1；上限由「每日 3 次 × 每好友 1 次」自然封顶 | `STEAL_RATE = 0.3`、`MIN_STEAL = 1` |
| 惩罚 | 每次偷菜好感 −2（每日最多 −6） | `STEAL_PENALTY_FRIENDSHIP = -2` |
| 互助正循环 | 帮浇水 +5、帮施肥 +10 好感（当日计数，鼓励正向社交） | `HELP_WATER_BONUS = 5`、`HELP_FERTILIZE_BONUS = 10` |
| 防护（建议） | 栅栏 / 护院 / 稻草人降低被偷概率或量，给玩家自主 | 代码 `isProtected` 已支持，外露为机制 |

**平衡提示（待确认）**：`floor(yield × 0.3)` 对 `yield ≤ 3` 实际 = `MIN_STEAL = 1`（即 33%~100%），与「30%」名义不符；建议 `yield < 10` 取固定 1、否则按比例，或文案标注「约 30%」。
**落地风险**：代码 `IsFeatureUnlocked` 恒返回 `true`，偷菜是否需等级解锁未定；建议 **Lv.2+** 开放并写入 GDD（见 A-11 F2 解锁阶梯表）。

## 4. 视觉风格（核心交付）

### 4.1 可偷指示
- 成熟可偷作物：叠加轻微**暖黄微光 / ✦** 或可爱 🤫 小标识，提示「可互动」。
- 受保护（栅栏/护院）作物：显示 🚧 / 🐕 盾形标识，灰化不可点。
- 已偷过：半透明灰 + ✅，当日不再可点。

### 4.2 偷菜动作
点击可偷作物 → 轻量确认气泡「偷走 N 个 X？」或直接「🤚 偷菜」按钮 → 执行时播**小手抓取 + 作物飞入背包**粒子动画 → 完成 toast「🤫 偷到 N 个 X！」。整体调皮但轻盈，不 aggress。

### 4.3 被偷提示（受害者侧，关键缺口）
受害者**下次进入自己农场 / 上线**时，弹出「📜 访客记录」：
- 「露娜 偷走了你的 3 个番茄（菜圃 B-2）」，列出被偷作物 / 数量 / 时间。
- 被偷地块短暂显示「空盆 + 🤫」状态。
- 语气温和、非指责；同时提示「可加栅栏防护」。

### 4.4 图标 / 配色规范
统一 emoji + 配色：可偷=暖黄微光、保护=蓝/绿盾、已偷=灰；主色对齐 `design/art/art-bible.md` 金（#8B6914）/ 绿（#4E7A3A）。

### 4.5 日志 UI
农场内「访客记录」入口 + 偷菜历史列表（谁 / 偷了什么 / 何时）；复用 `StealCropSystem.getStealLog` / `serialize`。

## 5. 与现有系统衔接

- **入口**：`FriendSystem`「偷菜」按钮 → `ctx.openStealVisit(f)` → `visit.lua` 2D 场景（已是 2D，顺带统一 2D 视觉语言）。
- **规则**：`StealCropSystem.canSteal / stealCrop / helpWater / helpFertilize` 判定与执行。
- **同步**：`StealCropNetwork` 已把偷菜/互助事件写云端。
- **缺口（需工程）**：目前仅偷菜者写 `steal_event_<stealerId>_`；**受害者侧需新增「按 `toUserId` 查询我的被偷事件」接口**（`StealCropNetwork.FetchMyStolenEvents`），支撑 4.3 被偷提示。被偷提示读取云端 + 本地 `serialize` 日志。

---

## 6. 优先级与范围

- 视觉风格 + 被偷提示：**本期设计定稿，随 A-10 工程落地**。
- 互助正循环：沿用现有规则，无需改动。
- 防护机制（栅栏/护院）：建议本期或下迭代（影响 farm 布局）。
