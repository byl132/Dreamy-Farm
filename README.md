# 🌾 梦境农场 · Dreamy Farm

> *"在梦境的田野里，种下希望，收获奇迹。"*

《梦境农场》是一款二次元田园生活模拟游戏。你将扮演一位厌倦城市生活的年轻人，继承远方亲戚留下的荒废农场，来到宁静的梦境村，从一块杂草丛生的土地开始，慢慢开垦田地、播种作物、浇水收获、经营牧场，并用自己的双手让农场重新恢复生机。

## 🎮 游戏特色

- **农场经营**：开垦、播种、浇水、收获，种植多种应季作物；饲养家禽家畜，经营牧场
- **四季与气候**：四季轮回 + 真实气候系统，雨雪、干旱、寒潮都会影响农作与生活节奏
- **室内场景**：可进入主屋、仓库、商店、铁匠铺、木匠小屋、御寒大棚，休息、烹饪、储物、买卖、打造、温室种植
- **村民社交**：结识小花、阿牛、林爷爷、老陈、小月等性格各异的村民，通过对话、送礼、任务融入村庄
- **逐步解锁**：随等级提升解锁钓鱼、动物养殖、村庄活动与更多探索内容
- **世界树传说**：游戏的长期目标不只是赚钱扩建农场，而是在日常中发现梦境村背后的秘密——收集线索、探索秘境，最终唤醒传说中的世界树

## 🕹️ 平台与入口

游戏基于 **TapTap Maker**（UrhoX Lua 引擎）开发，支持手机与电脑端。

## 📦 当前版本：V0.4.0

本版本主题：**让农场从"好看"变得"好玩"**——砍树玩法正式上线，并带来攒了一个多月的一大批体验优化和问题修复。

### ✨ 新增玩法

**砍树系统**

农场里的树全部可以砍了！走到树旁按 `F` 键（手机端点击「砍伐」气泡，或直接点击树旁的地面），抡起斧头就能开工：

- 每棵树需要砍 3 斧才会倒下：每砍一下树身都会摇晃、飘落树叶，近身提示实时显示砍伐进度
- 树倒下后掉落木材 ×3~5、树脂 ×1~2、树枝 ×1~3，并获得 5 点经验
- 原地留下树桩，3 天后自动长回新树，农场永远不缺木头
- 斧头开局随身携带（耐久 30），每挥一次消耗 1 点耐久、2 点体力；砍坏了可去商店花 50 金回购
- 挥斧有专属命中音效，大树倒下也有轰然倒地声
- 「砍伐」模式已加入底部工具栏，电脑端按快捷键 `6` 一键切换

**角色真的拿着斧头**

- 选中「砍伐」模式后，角色全程手握斧头（木质斧柄 + 钢制斧刃）
- 每次挥砍都有完整动作：举斧过头 → 奋力劈下 → 缓缓收势
- 切换到锄头、水壶等其他工具时，斧头自动收起

**砍树新手教程**

- 新手引导新增砍树教学：带你走到最近的树旁，手把手教你抡斧砍树、收获木材

**院落栅栏与自动院门**

- 家院子四周换成真正挡人的木栅栏，四角严丝合缝
- 唯一出入口是院子大门：走近自动打开、通过后自动关上

**中英文双语**

- 开始页和设置页新增一键语言切换，主菜单、登录、账号云存档等主要界面均已支持英文

### ⚡ 体验优化

- 设置页全新改版：固定双栏布局，手机单列、桌面双列自适应，窄屏与高 DPI 屏幕不再裁切
- 多人联机改为后台秒开匹配，不再需要进独立大厅等待
- 接入真实激励视频广告，完善失败与超时自动恢复
- 云存档统一使用官方账号身份，数据更安全
- 打开设置时自动隐藏小地图，视野更清爽
- 补齐铁匠老刘、商人马可、村医王大夫 3 张 NPC 头像
- 优化渲染性能，移除遮挡全场景的天空渐变层，游戏更流畅
